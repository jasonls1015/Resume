# Writing Samples

Thanks for visiting my online portfolio. I'm Jason Langkamer-Smith, a senior technical writer with more than 20 years of experience building high‑quality hardware, software, and API content for global engineering teams.

These case studies and samples span API documentation, an AI-powered answer bot, structured end-user help content, tech comms production work, custom scripting to solve a documentation problem, and my graduate research on document usability.

## Case Studies

### Disambiguating Status Codes
How I documented two related but distinct concepts, both casually called "status codes," and how that same ambiguity had to be solved a second time for an internal AI support tool trying to answer questions about them.

[Read the case study](API-Documentation.md)

### ROOTS: AI Answer Bot
A Slack-integrated RAG tool I designed and built, using Claude in Amazon Bedrock to answer developer questions about the API with cited sources. Covers the retrieval problems I identified and fixed, and the case for retrieval quality as a documentation skill.

[Read the case study](ROOTS-Case-Study.md)

### Structured Markdown & Semantic Authoring
A docs-as-code approach to end-user help content, using Writerside's semantic markup for conditional text, variables, and reusable procedures across multiple products from a single source. Includes a worked login procedure and its rendered output.

[Read the case study](Markdown.md)

### Automation & Scripting: FrameMaker ExtendScript
A custom script I wrote to catch inconsistent bit field notation across long hardware specifications, an early example of solving a documentation-quality problem with code rather than manual review.

[Read the case study](ExtendScripts.md)

### Legacy Publications: White Paper Production
Editing, layout, and production work on external-facing technical white papers, representative of a steady, recurring part of my Intel workload.

[Read the case study](White-Papers.md)

### Document Usability Research
My NJIT Master's thesis, an empirical study testing whether decision tables versus numbered lists affect perceived credibility and validity of procedural content, and whether that effect holds across cultures. The research behind a design decision I still make on nearly every project.

[Read the case study](Document-Usability-Research.md)

## A Note on Confidentiality

These samples describe process, architecture, and my own contributions, not proprietary source material. Where relevant, I link to live, public documentation as proof of work rather than reproducing content that belongs to a former employer.
